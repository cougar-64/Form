# Project instructions

Implement Form incrementally using the approved milestone plan in the conversation. The stack is Expo, TypeScript, and SQLite. Keep plans, dated occurrences, and actual sessions separate as those features are introduced.

After each task that changes project files, append an entry to `AI-ATTRIBUTION.md` in this root, creating it if necessary. Use today's date and this format:

```text
YYYY-MM-DD: <each file changed, with (new file) after new ones>
• Tool: <tool name>
• Task: <the user's task, in one or two sentences>
• Review: TODO
```

List every project file changed or created, including tests and the attribution file itself. Do not list unchanged files. Leave Review as TODO for the user to fill in.
